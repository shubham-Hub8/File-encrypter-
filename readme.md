# Simple File Encryptor

Simple File Encryptor is a browser-based application that securely encrypts and decrypts files using modern cryptography.

All encryption happens locally inside your browser using the Web Crypto API.

Your files and passwords never leave your device.

## Features

- Client-side AES-GCM encryption
- Password-based key derivation
- Multiple files and folder selection
- Encrypted ZIP export
- Drag & Drop support
- Offline capable
- No account required
- No uploads
- Modern responsive interface

## Security

- AES-256-GCM
- PBKDF2 (SHA-256)
- Random IV
- Random Salt
