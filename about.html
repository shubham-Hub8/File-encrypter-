About Simple File Encryptor

Private, local file encryption with a simple interface.

What is Simple File Encryptor?

Simple File Encryptor is a lightweight browser application that encrypts and decrypts files directly on your device using the Web Crypto API. Your files remain on your device throughout the entire process—nothing is uploaded to a server.

Features

  • 🔒 Password-protected file encryption.
  • 🔓 Secure file decryption.
  • 📂 Drag & Drop support.
  • 📁 Manual file picker.
  • 📊 Password strength indicator.
  • ⚡ Fast browser-based processing.
  • 📱 Mobile and desktop compatible.
  • 🌐 Works completely offline after loading.
  • 💾 Automatic download of processed files.
  • 📦 Supports files up to 1 GB.
  • 📁 Supports selecting folders and multiple files.

How It Works

When you encrypt a file, your password is converted into a secure cryptographic key using your browser's Web Crypto API. The file is then encrypted locally before being downloaded back to your device.

To decrypt the file, simply select the encrypted file and enter the same password that was used during encryption.

Privacy

  • Your files never leave your device.
  • Your password is never stored or transmitted.
  • No user accounts.
  • No cloud storage.
  • No advertisements.
  • No analytics or tracking.

Security Notes

  • Use a strong, unique password.
  • Keep backups of important files before encrypting.
  • If you forget your password, encrypted files cannot be recovered.
  • The application relies on your browser's built-in Web Crypto API.

Frequently Asked Questions

Does this upload my files?

No. Everything happens locally in your browser.

Can I use it offline?

Yes. Once the application has loaded, it can continue working without an internet connection.

Is there a file size limit?

Yes. The current maximum supported file size is 1 GB.

Can I recover a forgotten password?

No. Without the correct password, encrypted files cannot be decrypted.
