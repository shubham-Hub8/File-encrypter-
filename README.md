# File-encrypter- (USE: https://securefileencrypter.netlify.app/)
Simple File Encrypter is a free open source web app that lets you lock any file with a password in seconds. Just upload your file, set a password, and download the encrypted version, no installs, no sign-ups. Perfect for protecting personal documents, photos, or sensitive data before sharing or storing them online. Fast, private, and easy to use.

important note; Supports option 1 GB file, may not be suitable for most low end devices and it relies on hardware too. yes you're allowed to modify this but it will be mine. USE THE ZIP OR EXTRACT IT IN A NEW FOLDER AND USE IT
