# File-encrypter- (USE: https://securefileencrypter.netlify.app/)
Simple File Encrypter is a free web app that lets you lock any file with a password in seconds. Just upload your file, set a password, and download the encrypted version, no installs, no sign-ups. Perfect for protecting personal documents, photos, or sensitive data before sharing or storing them online. Fast, private, and easy to use.
