SIMPLE FILE ENCRYPTOR 2.0 — FINAL RELEASE

This release is a standalone offline web application.

Usage:
1. Extract the ZIP.
2. Double-click index.html, or use Open with → Chrome, Edge, Firefox, or another modern browser.
3. No Node.js, npm, local server, CDN, or internet connection is required.

Cryptography:
- Argon2id v1.3 / RFC 9106, implemented locally in js/argon2id.js.
- AES-256-GCM via the browser Web Crypto API.
- 16-byte random salt and 12-byte random nonce per encrypted file.
- SFE2 header is authenticated as AES-GCM AAD.
- Existing SFE1 encrypted files remain decryptable for compatibility.

Release QA:
- Argon2id RFC 9106 test vector verified against the published 32 KiB / 3-pass / 4-lane vector.
- AES-GCM SFE2 round-trip verified.
- Source scripts pass Node syntax validation.
- No runtime external dependencies are present.

The browser must have JavaScript, Web Crypto, and BigInt support. High memory settings can require substantial RAM; 64 MiB is the default.
